# Technology Consultant Academy Landing Page: Content Specification

## 1. Project Overview

### 1.1 Project Description
Landing page for a technology consulting academy targeting Gen Z and working professionals, specializing in Business Applications, AI, and Cloud Computing with emphasis on interpersonal skills and business process knowledge.

### 1.2 Core Principles
- **Simplicity**: Clean interfaces, intuitive navigation
- **Elegance**: Sophisticated design aesthetic
- **Mobile-First**: Optimized for mobile devices first
- **Gen Z Appeal**: Authentic content, visual storytelling
- **Speedway Theme**: Subtle metaphor for maximizing potential and career acceleration

### 1.3 Primary Objectives
- Present the academy's unique philosophy and approach
- Showcase course offerings with emphasis on Business Applications and AI
- Provide an interactive skill assessment tool with scholarship opportunities
- Facilitate simple enrollment process
- Emphasize career outcomes at top consulting firms

## 2. Page Content Sections

### 2.1 Header
- Academy logo
- Navigation links to main sections
- Primary call-to-action button

### 2.2 Hero Section
- Headline emphasizing unique value proposition
- Brief subheading highlighting key differentiators
- Primary and secondary call-to-action buttons

### 2.3 Academy Philosophy Section
- Section heading
- Introduction paragraph (max 50 words)
- Three philosophy pillars, each with:
  - Title
  - Brief description
  - Icon or visual element

### 2.4 Unique Approach Section
- Section heading
- Three-part approach presentation:
  1. **Interpersonal Skills**: Accountability, learnability, resilience
  2. **Industry Knowledge**: Business process understanding, sector expertise
  3. **Technical Expertise**: Technology stack skills, certification pathways

### 2.5 Course Offerings Section
- Section heading
- Course filtering system with three categories:
  - **Business Applications** (prominent): Salesforce (CX focus), Oracle (ERP focus), Microsoft (SCM focus)
  - **AI Consulting** (prominent): Natural Language Processing, Computer Vision, Predictive Analytics, Generative AI Solutions, MLOps
  - **Cloud Computing**: AWS, Azure, GCP
- Each course should contain:
  - Title
  - Technology focus
  - Brief description
  - Key learning outcomes (3 points)
  - Expandable details

### 2.6 Hardware & Connectivity Requirements
- Standard Chromebooks or basic laptops are sufficient
- Minimum internet speed requirement: 10+ Mbps
- Browser-based learning platform

### 2.7 Program Structure & Time Commitment
- 12-week course duration
- 40 hours per week time commitment
- Weekly schedule breakdown of activities

### 2.8 Assessment Framework
- Explanation of modular assessment approach
- Types of assessments:
  - Theoretical questions (multiple choice)
  - Timed "cold call" open-ended responses
  - Real-world problem scenarios
- Progress tracking methodology

### 2.9 Skill Assessment Tool
- Introduction to assessment purpose
- 10-15 questions covering aptitude and interests
- Results showing:
  - Skill level visualization
  - Personalized recommendations
  - Scholarship/rebate eligibility
  - Course matching

### 2.10 Group Enrollment Options
- Group enrollment benefits and pricing advantages
- Simple contact form for group inquiries

### 2.11 Global Accessibility
- English as primary language of instruction
- Asynchronous mentor communications
- Self-paced structure for different time zones
- Tutor availability across time zones

### 2.12 Mentor Support Framework
- "Meet the Mentors" gallery with expertise highlights
- Mentor matching approach
- Available interaction methods (video, chat, etc.)
- Ongoing nature of mentor relationships

### 2.13 Learning Content Structure
- Sample content modules showing multimedia approach
- Content types (articles, videos, exercises)
- Accessibility features
- Self-paced journey structure

### 2.14 Journey Visualization
- Career progression timeline from:
  - Soft skills foundations
  - Technology learning modules
  - Real-world scenario assessments
  - Project shadowing opportunities
- Estimated timeframes and milestones

### 2.15 Community & Collaboration Features
- Virtual classroom environment
- Peer-to-peer learning opportunities
- Discussion forums
- Collaborative project spaces

### 2.16 Progress Monitoring System
- Tutor dashboard capabilities
- Checkpoint notification system
- Performance analytics
- Support intervention points

### 2.17 Career Transition Support
- Resume building resources
- Job application process
- Interview preparation resources
- Employer partnerships

### 2.18 Industry Tools Integration
- Access to actual industry software tools
- Specific tools for each domain:
  - Business Applications tools
  - AI development tools
  - Cloud platform tools
- Hands-on practice methodology

### 2.19 Content Update Cycle
- Course updates aligned with software release cycles
- Industry development integration
- Learning latest versions of tools

### 2.20 Data Privacy Section
- Data collection practices
- Use of data for learning optimization
- Third-party sharing policies

### 2.21 Success Stories & Outcomes
- Placement rate data
- Salary increase statistics

  - Name (required)

  - Phone (optional)

  - Area of interest
  - Referral source
